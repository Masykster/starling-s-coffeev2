## 📖 Tentang Proyek

**Starling's Coffee v2** adalah website profil perusahaan (company profile) untuk sebuah kedai kopi modern. Proyek ini dibangun untuk menampilkan identitas brand, daftar menu, dan memberikan informasi lokasi serta kontak kepada pelanggan.

Fokus utama dari versi ini adalah **User Experience (UX)** dan **Visual Aesthetics** yang mencerminkan suasana kedai kopi yang hangat dan premium.

---

## 🚀 Peningkatan di v2

Apa yang baru dibandingkan versi sebelumnya?
* ✅ **Modern UI/UX:** Desain ulang total dengan tipografi dan palet warna yang lebih elegan.
* ✅ **Mobile Responsive:** Tampilan yang menyesuaikan sempurna di smartphone, tablet, dan desktop.
* ✅ **Animasi Halus:** Transisi dan efek hover yang membuat interaksi terasa lebih hidup.
* ✅ **Kode yang Lebih Bersih:** Struktur kode yang lebih rapi dan mudah dikelola (Maintainable).

---

## ✨ Fitur Utama

* **Homepage Imersif:** Hero section dengan visual yang kuat untuk menarik perhatian pengunjung.
* **Menu Digital:** Tampilan daftar menu kopi dan makanan dengan harga dan deskripsi.
* **About Us:** Cerita di balik brand Starling's Coffee.
* **Contact & Lokasi:** Formulir kontak (opsional/fungsional) dan integrasi peta/alamat.
* **Social Media Links:** Terhubung langsung ke platform sosial media kedai.

## ⚡ Instalasi & Penggunaan

Ikuti langkah ini untuk menjalankan website di komputer lokal (Localhost):

### Jika menggunakan PHP (XAMPP/Laragon):
1.  **Clone Repositori**
    Masuk ke folder `htdocs` (untuk XAMPP) atau `www` (untuk Laragon).
    ```bash
    git clone [https://github.com/Masykster/starling-s-coffeev2.git](https://github.com/Masykster/starling-s-coffeev2.git)
    ```
2.  **Jalankan Server**
    Buka Control Panel XAMPP dan start **Apache**.
3.  **Akses Browser**
    Buka browser dan ketik: `http://localhost/starling-s-coffeev2`

### Jika Static HTML (Tanpa PHP):
1.  **Clone Repositori**
    ```bash
    git clone [https://github.com/Masykster/starling-s-coffeev2.git](https://github.com/Masykster/starling-s-coffeev2.git)
    ```
2.  **Buka File**
    Masuk ke folder proyek dan klik dua kali file `index.html`.
